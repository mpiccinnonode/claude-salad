## CAPABILITIES.md

`CAPABILITIES.md` describes what this project does for colleagues who are not developers; the `/capabilities` skill reads it across every org project.

- When a change adds, removes or changes something a user or client can do, or adds/removes an external service, update `CAPABILITIES.md` in the same change and set `updated:` to today.
- Plain words, Italian, no code paths, versions, tech debt or security details. Technologies by name only.
- Keep the frontmatter keys and the three sections ("Cosa sa fare", "Servizi esterni", "Da sapere") as they are — the org index depends on them.
